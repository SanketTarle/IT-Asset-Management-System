Database Architecture & Backup Guide
Automated SQLite Architecture

This installation uses zero-configuration SQLite. The database is stored in database.db in the application root directory.

  • Database automatically initialized on first run with full schemas and default administrator.
  • No external MySQL, PostgreSQL, or database daemon required.
  • Transactions and relationship cascades protect data integrity.
